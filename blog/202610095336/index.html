tpm ssh with macos

#ssh #git #security

Soc Virnyl Estela | 2026-10-05T01:53:43Z | reading time: ~2min

while looking for a way to find an equivalent for https://uncomfyhalomacro.pl/blog/using-ssh-keys-with-tpm-and-git/, i finally figured it out.

you can use any package manager for this as long as you can install the following

  • https://www.softhsm.org/
  • https://github.com/Mastercard/pkcs11-tools

i am using homebrew so the commands to install them are

brew install softhsm pkcs11-tools

to initialize, you must create a virtual smartcard via softhsm

softhsm2-util --init-token --slot 0 --label "ssh"

you are then prompted to fill in the Security Officer PIN (so-pin) and the PIN (user PIN). do not lose and forget the so-pin as it's important for passphrase reset if you ever forgot the user PIN.

next is to initialize a keypair via p11tool

p11tool --provider /opt/homebrew/Cellar/softhsm/2.7.0/lib/softhsm/libsofthsm2.so --login --generate-privkey=ed25519 --label "ssh-tpm-sign"

it should give you a similar output like

warning: no --outfile was specified and the generated public key will be printed on screen.
Generating an EdDSA (Ed25519) key...
Token 'ssh' with URL 'pkcs11:model=SoftHSM%20v2;manufacturer=SoftHSM%20project;serial=3bc38ba308914d10;token=ssh' requires user PIN
Enter PIN:
-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEA+t1Su91K3WkkcQo3NB6xFX4up9w56AWVqg3NVd2hpnQ=
-----END PUBLIC KEY-----

you can test that it works via ssh-keygen

> ssh-keygen -D /opt/homebrew/Cellar/softhsm/2.7.0/lib/softhsm/libsofthsm2.so
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIPrdUrvdSt1pJHEKNzQesRV+LqfcOegFlaoNzVXdoaZ0 ssh-tpm-sign

but there is a problem. your ssh-agent does not know how to resolve this if it's looking for its private key. to do that, you must run another ssh-agent in the background (or possibly, edit the launchd config for the ssh-agent but i will not cover that cause this one's simpler).

add this in your shell rc i.e. ~/.bashrc or ~/.zshrc

export PKCS11LIB="/opt/homebrew/lib/softhsm/libsofthsm2.so"
SSH_ENV="$HOME/.ssh/custom_agent_env"

start_custom_agent() {
    echo "Starting new custom ssh-agent..."
    ssh-agent -s -P '/opt/homebrew/Cellar/softhsm/*/lib/softhsm/*' | sed 's/^echo/#echo/' > "$SSH_ENV"
    chmod 600 "$SSH_ENV"
    source "$SSH_ENV"
}

if [ -f "$SSH_ENV" ]; then
    source "$SSH_ENV" > /dev/null
    if ! ps -p $SSH_AGENT_PID > /dev/null; then
        start_custom_agent
    fi
else
    start_custom_agent
fi

take note of the PKCS11LIB

if you don't add that, you'll be met by something like this when you run the following

> killall ssh-agent
> eval $(ssh-agent)
Agent pid 50918
> touch newfile
> ssh-add -l
The agent has no identities.
> ssh-add -s /opt/homebrew/Cellar/softhsm/2.7.0/lib/softhsm/libsofthsm2.so
Enter passphrase for PKCS#11:
Could not add card "/opt/homebrew/Cellar/softhsm/2.7.0/lib/softhsm/libsofthsm2.so": agent refused operation
> git commit --signoff -m 'add newfile'
error: No private key found for public key "/Users/socwork/.ssh/id_tpm_sign.pub"?

fatal: failed to write commit object

once you added that new script to your shell rc, open a new terminal window and you can add the ssh private key via ssh-add
